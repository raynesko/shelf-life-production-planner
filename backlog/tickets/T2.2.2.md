## Description
Implement src/shelflife/plant/changeover.py. Rule: changeover i->j = base time (label/format) + allergen clean time if SKU i carries any allergen NOT declared on SKU j (residue would be an undeclared allergen); smaller clean/flavour-change time otherwise; allergen-free to anything is cheap. Times come from config ranges (assumptions; no public per-line dataset exists - flag it). Also calibrate a demand scale factor so that the baseline-style weekly load (production hours + changeovers) averages ~85% of available hours (a TARGET calibration assumption) and save to configs/calibration.yaml.

## Acceptance criteria
- [ ] pytest: for 10 hand-written SKU pairs, the matrix matches the expected clean/no-clean decision (incl. subset case: i={milk}, j={milk,soy} needs no allergen clean; i={milk,soy}, j={milk} does)
- [ ] Matrix is asymmetric where the rule says it should be; diagonal is 0
- [ ] docs/figures/changeover_heatmap.png exists
- [ ] configs/calibration.yaml contains scale_factor and the achieved mean utilisation (printed by scripts/calibrate.py)
- [ ] Changeover time ranges are listed in docs/assumptions.md as ASSUMPTION with low/base/high values
