## Description
src/shelflife/checks/plan_checker.py re-validates any plan (baseline or optimised) against capacity, run-size limits, shelf-life/min-remaining rules and allergen/changeover accounting. It must not import the optimiser module, so it is an independent check.

## Acceptance criteria
- [ ] Checker module has no import from shelflife.opt (verified by a test that scans imports)
- [ ] 5 mutation tests: deliberately corrupted plans (over capacity, below min run, wrong changeover accounting, expired shipment, missing clean) are all rejected with specific messages
- [ ] Baseline and optimised toy plans both pass
- [ ] CLI: `python -m shelflife.checks.plan_checker <plan.parquet>` prints PASS/FAIL list
