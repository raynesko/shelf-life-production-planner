## Description
Create configs/plant.yaml for a hypothetical refrigerated prepared-foods plant: one filling/packing line (the single bottleneck), weekly buckets. For each of 12 SKUs: family, allergen set (subset of the Big 9, assigned by family with rationale), shelf life at manufacture (days; anchored to USDA FoodKeeper ranges for comparable products where one exists, otherwise flagged ASSUMPTION), line rate (cases/h), minimum and maximum run size, unit cost. Line: weekly available hours (e.g. 2 shifts x 5 days x 8h less planned sanitation/maintenance), minimum remaining shelf life at shipment (%). Every parameter carries a `source:` field = citation URL | 'assumption' + plausible range.

## Acceptance criteria
- [ ] configs/plant.yaml loads through a pydantic (or dataclass) schema in src/shelflife/plant/config.py with validation errors on missing source
- [ ] Every parameter has a non-empty source; count of 'assumption' parameters is printed by `python -m shelflife.plant.config --report`
- [ ] Allergen sets only use the 9 FDA major allergens (validated in code)
- [ ] Shelf lives are 14-56 days for all SKUs (weekly-bucket model is invalid outside this; documented)
- [ ] docs/assumptions.md created with one row per assumption: ID, value, range, source, sensitivity-tested (Y/N, link)
