## Description
src/shelflife/sim/engine.py. Weekly loop given a production plan (quantity and sequence per week) and a demand path: add production as a new age-0 cohort; ship FEFO only units that satisfy minimum remaining shelf life; expire units older than shelf life (integer weeks); record lost sales on shortfall; compute changeover hours from the sequence (including carry-over from last week's final SKU) and flag capacity breaches. Output weekly KPI table per kpi_definitions.md.

## Acceptance criteria
- [ ] pytest invariant over 1000 random plans: produced = shipped + expired + ending inventory (+ initial inventory) for every SKU
- [ ] A hand-computed 3-SKU x 4-week example (committed as tests/fixtures/handcalc.md and .json) matches simulator output exactly
- [ ] Simulator is deterministic (same inputs -> identical KPI frame)
- [ ] KPI column names match docs/research/kpi_definitions.md
- [ ] 52-week x 12-SKU simulation runs in < 5 seconds
