## Description
Implement baseline B1, a realistic good-practice spreadsheet planner, NOT a strawman: forecast = 4-week moving average; weekly production = forecast demand + fixed 1-week cover top-up, scaled pro-rata if capacity is exceeded; sequence = fixed static 'allergen ladder' (fewest allergens first, most last, wet clean at end of cycle); FEFO. Document why this is fair and what it deliberately does not do (no shelf-life awareness, no dynamic sequencing).
